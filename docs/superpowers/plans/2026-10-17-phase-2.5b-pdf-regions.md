# Phase 2.5b: PDF Preview and Region to Prompt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The preview shows PDFs (continuous scroll, page field, zoom, selectable text). In a PDF or image preview the user marks a region, types a comment, and Add puts the crop and the comment into the focused session's input, unsent.

**Architecture:**
- **Core.** Two token-checked routes. `POST /v1/sessions/{tab}/attachments` takes a PNG and saves it under `~/.marshell/attachments/<tab>/`, returning its name, absolute path and the agent's reference for it. `POST /v1/sessions/{tab}/paste` writes that reference and the comment into the session as two bracketed pastes, with no Enter. The content route gains `kind=pdf` with its own cap.
- **Frontend.** `src/features/preview/pdf/` loads pdf.js lazily and renders pages as they scroll into view. `src/features/regions/` holds the pure geometry, the crop, the box overlay and the comment popover. `LiveApp` delivers: a paste for an agent, the clipboard for a manual CLI.
- **Why paste, not the prompt line.** The live app runs with `composer={false}` until phase 3. The user chose (2026-10-17) a bracketed paste into the agent's own input, which is what pasting by hand does; when the prompt line goes live, delivery switches to filling it.

**Tech Stack:**
- Rust core: axum, tokio and the existing `vt100` screen (its `bracketed_paste()` flag). No new Rust dependency.
- Frontend: React, TypeScript; new dependency `pdfjs-dist` (PLAN §2.5 names pdf.js).
- Tests: `cargo test --workspace`; Vitest in the node environment (no DOM, so components get `renderToStaticMarkup` tests and logic lives in pure modules).

**Spec:**
- `docs/PLAN.md` §2.5 (lines 846–862): region to prompt, delivery rule, multi-CLI `attachment_ref`, storage, security, new dependencies, exit criteria.
- `docs/PLAN.md` "Slice 2.5a decisions" (line 824): the preview this builds on.
- Research: the Sonnet notes of 2026-10-17 at `C:\Users\HOMEOF~1\AppData\Local\Temp\claude\C--dev-Airport\411ddd9b-48ca-48e9-ac1e-63f07c07aebb\scratchpad\attachment-ref-research.md` (moved into `docs/research/attachment-ref.md` by Task 8). Codex attaches an image only when one bracketed paste is exactly one image path; Claude Code treats a pasted image path as an image.
- The user's 2026-10-17 answers for 2.5b:
  1. Delivery: a bracketed paste into the terminal, no Enter. The image path goes as its own paste. A manual CLI gets the clipboard and a notice.
  2. PDF: continuous scroll, pages rendered as they come into view, a "Page 3 of 12" field you can type into, fit width plus zoom, selectable text.
  3. Comment: a small popover anchored to the box, flipping to stay on screen, with Add (Enter) and Cancel (Esc).
  4. Keyboard: a "Select region" button and R (while the preview has focus) show a movable box; arrows move, Shift+arrows resize, Ctrl+arrows step 1 px, Enter opens the comment, Esc cancels. With the mouse you drag in that mode.
  5. After Add, focus goes to the session's terminal; the preview stays open.
  6. One region per Add; more regions append to what is already in the agent's input.

## Global Constraints

- **Dependencies.** Only `pdfjs-dist` is new (frontend). No new Rust crate.
- **pdf.js stays lazy and CSP-safe.** Reached only through dynamic `import()`, never in the main chunk. `getDocument` gets `isEvalSupported: false` and `useWasm: false`, so the CSP keeps out `'unsafe-eval'` and `'wasm-unsafe-eval'`. The worker is loaded from `'self'` (`pdfjs-dist/build/pdf.worker.min.mjs?url`). The CSP in `src-tauri/tauri.conf.json` does not change. If the installed version has no `useWasm` option, stop and report rather than loosening the CSP.
- **Caps.** PDF 50 MB (50 × 1024 × 1024), defined in the core's `files.rs` as `PDF_CAP` and mirrored in `previewApi.ts`. An attachment upload is at most 20 MB (the image cap). A crop's longest side is at most 4096 px; a rendered page canvas is at most 16 777 216 px.
- **Delivery rule.** Marshell never sends Enter. The paste route refuses any control character (U+0000–U+001F, U+007F) in the comment, so a comment can't end a bracketed paste early or press Enter. Comment text is at most 2000 characters.
- **Storage.** `<home>/attachments/<tab>/<unix ms>.png` (`-2`, `-3`… on a clash), folder through `store::create_private_dir`, file through `store::write_private_file` (owner-only on Unix). Nothing deletes them in this slice; retention is phase 5.
- **Multi-CLI.** The reference comes from `profiles::detect::attachment_ref(agent, path)`. Today it is the double-quoted absolute path for claude, codex, antigravity and the default; each agent has its own match arm so a later change stays scoped.
- **Copy** (sentence case, plain words):
  - Button: "Select region" (title "Select region (R)").
  - Popover: field label "Comment", placeholder "What should the agent look at?", buttons "Add" and "Cancel"; target line "Adds to <name>" or "Copies to the clipboard".
  - Notices: "Added the region to <name>." · "<name> has no prompt line, so the region is on the clipboard." · "No session to add it to." · "Couldn't add the region: <reason>"
  - PDF: "Page" field with "of <n>", "Zoom out", "Zoom in", "Fit width"; errors "This PDF can't be shown." and "This PDF is password-protected."
  - Paste text: `<label>: <comment>`, or `<label>` alone with no comment; label is `<file name>, page <n>` for a PDF and `<file name>` for an image.
- **Look.** Styles go through the `frontend-design` skill (and `good-css` if installed). Forced colors, reduced motion and both themes are handled; the box differs from its surroundings in shape, not only colour.
- **Generated types.** After changing `crates/protocol`, run `cargo test -p marshell-protocol` and commit `src/generated`; `pnpm check:generated` must pass. Run `cargo fmt --all` before each commit that touches Rust (CI checks it).
- **Platform.** Windows 11 is the only tested platform; keep the Unix branches compiling in shape (`#[cfg(unix)]` helpers already exist).

## Review Focus

1. **A broken or locked PDF.** A corrupt file or one with a password must show its one-line message, never a spinner forever. Pinned by `pdfErrorMessage` tests in Task 4.
2. **The file changes while a box is up.** The box survives a reload (it is kept in page fractions); if the page it sits on no longer exists, select mode ends. Pinned by `regionStillValid` tests in Task 5.
3. **The focused session changes, closes or is a shell while the popover is open.** Add goes to whichever session is focused at the moment of Add; none gives "No session to add it to."; a manual CLI goes to the clipboard. Pinned by `deliveryFor` tests in Task 7.
4. **A pasted multi-line comment.** The single-line field turns line breaks and tabs into spaces before sending, so the core's control-character refusal never surprises the user. Pinned by `regionText` tests in Task 5 and the 400 test in Task 2.
5. **A huge page or a deep zoom.** The crop stays within the canvas limits instead of failing silently. Pinned by `cropScale` tests in Task 5.

### Task 5: Region geometry, crop and paste text

**Files:**
