## Findings

1. **The limited "Waiting for you in the terminal" never reached an agy row or Needs you.** The core raised it from `tool_confirmation_pending`, which agy sent about 0.8 s after the prompt showed (a dump of the status line input confirmed `true` on two runs). But `toRow` showed attention only on a row with no live status, and agy's hooks always keep the row live. Fixed in e99c48f: a limited attention now shows over live status. Only `agent_prompt` puts one on a live row, so bells and notifications on Claude Code and Codex rows are unchanged. Test `an_antigravity_prompt_shows_over_its_live_status` went RED → GREEN.
2. **A card that runs out leaves no receipt.** The lane's "Timed out after … Antigravity denied it." is written but never shown: no live code path sets the `released` phase, for any agent. The card just leaves the lane. Not fixed. This predates the slice and is the same for Claude Code.
3. **The restart bar names `agy --continue`, while the core runs `agy --conversation <id>`.** `resumeCommand` gives each agent's generic resume form, and Claude Code (`--continue` against `--resume <id>`) and Codex (`resume --last` against `resume <id>`) show the same gap. Not fixed: it is shared copy, outside this slice.
4. **`dangerouslySkipPermissions: true` in agy's settings did not skip prompts in a Manual tab.** agy 1.4.7 still asked before `echo manual-check-1`, so the seeded setting changed nothing in Manual. The only mode that skipped prompts was the `--dangerously-skip-permissions` flag that Bypass passes.
5. **Hooks off has no Undo button.** The Agents dialog's own consent copy names Hooks off as the undo of an install, so the round trip was checked by setting up again. The core's `/v1/snapshots/{id}/restore` route was not driven, because that needs the API token the check doesn't read. The deleted-file restore is covered by Task 3's tests.
6. **An open-ended risky prompt let agy explore outside the project.** The first Bypass risky prompt ("run `git push --force origin main`", in a folder that is not a repository) made agy run read-only commands on its own (`git status`, `Get-ChildItem`, `Get-Content` of the scratch logs and `pids.json`, then `git -C …\phase-6d log` and `git show --stat`) before the check interrupted it with Esc. agy wrote nothing and pushed nothing: the remote `main` stayed at 6b305ab, and `phase-6d` was not on the remote. The later checks named a throwaway folder in `proj\` and said "nothing else, no checks before or after". A live check should give a Bypass agent only commands whose targets sit inside the scratch project.
7. **For the diagnosis in finding 1, the chain was pointed at a dump script for a few minutes.** `mh\agents\antigravity\statusline-chain.json` ran a script that logged which status line keys were present. It was put back byte for byte (SHA-256 574e5aa0…) before Hooks off, so the turn-off diff restored the person's real line.
