## Findings

1. **Tab skipped "Show the files".** Focus went from the row's "Open Agents" straight to the page's "Close". The Doctor page's focus trap moves focus itself, over a list of elements that had no `summary` in it, so the disclosure could be opened only with a pointer. Fixed in `edc22d1a`: the trap's list (`FOCUSABLE` in `src/lib/dialogFocus.ts`) and the test helper that mirrors it (`focusOrder`) both take a `summary`. The test "the page's focus trap walks the disclosure, so Tab reaches it" failed first. The list is shared, so a disclosure in any other dialog is now a tab stop too.
2. **Codex's cut item named its config file in two path forms.** With a Codex home outside the home folder the last sentence read "Set project_doc_max_bytes in `<Codex home>`/config.toml", backslashes then a slash. Fixed in `6b770dda`: the file's own path is shown, `~/.codex/config.toml` under the home folder and the full path elsewhere. `a_codex_home_outside_the_home_folder_names_its_config_file_in_one_form` failed first.
3. **Claude Code's rows include the PC's real `.claude\CLAUDE.md`.** Every project's Claude Code figure holds about 1.3k tokens from `<real home>\.claude\CLAUDE.md`, shown by its full path. The scratch projects sit under the real home folder, Claude Code walks up from a project and loads a `.claude\CLAUDE.md` it passes, and the scratch `CLAUDE_CONFIG_DIR` means that file isn't the user's own file here. The Doctor only read it. Not a defect: without a moved `CLAUDE_CONFIG_DIR` the same file is the user's own and is counted once as that. A later check that needs clean Claude Code figures puts its projects outside the real home.
4. **Codex warns about the user file as well, and the Doctor has no item for it.** Codex also printed "warning: Combined user instructions use 33025 bytes, above the 32768-byte `project_doc_max_bytes` setting. The total includes global and thread instructions. The limit applies only to project files." The Doctor counts the user file (59 tokens) in the line and the Waste item, and by Codex's own words nothing of it is cut. Not fixed.
5. **An `AGENTS.md` that `CLAUDE.md` imports had two rows.** In `pA` Claude Code listed it under `CLAUDE.md` as loaded and again as "not loaded: CLAUDE.md is here". The pre-merge review pointed at the second row, which reads as if the file didn't load. Fixed after the check: a file an earlier file imported is listed once, as loaded. `an_agents_md_that_claude_md_imports_is_listed_once_as_loaded` failed first.
6. **Byte counts read "32768" beside "24,000".** Codex's items write the number bare, Antigravity's with a comma (already a deferred minor of the final review). Not fixed.
