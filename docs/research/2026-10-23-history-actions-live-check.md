## Findings

1. **A resumed or forked session's terminal didn't take focus when another session was open.** `TerminalView` makes its terminal only after its font has loaded. The effect that focuses it ran at mount, before that, and nothing re-ran it. A traced Resume made no `focus()` call at all, and focus stayed on `<body>`. The first tab ever opened got focus some other way, which is why 5a saw it work. The bug has been on main since dcb1ac7 and hit every new session opened from History. Fixed in 3867d1e: the effect also runs on `fontReady`, with a source check in `TerminalView.test.tsx` that failed first. Re-checked live: Resume with four sessions open made one `focus()` call, and focus landed in "Session 5, terminal: Retry plan v2 5".
2. **Not seen live: a rename reaching a running tab, and back.** After the History rename to "Retry plan v2", the resumed tab kept its old name. The core renames a tab only when that tab's newest recorded conversation is this one. That link comes from Claude Code's hooks, and this run had none (limited status, and Claude Code stopped at its first-run screen). For the same reason, resuming b1 again was not refused, and the second resumed tab got the de-duplicated name "Retry plan v2 4". This is by design without hooks. Both directions are covered by `renaming_a_running_conversation_renames_its_tab` and `renaming_a_tab_names_its_conversation_and_the_next_one`.
3. **The markdown export keeps HTML in a title as it is.** The saved file starts `# Retry <img src=x onerror=alert(1)> plan`. A viewer that renders HTML in markdown would show it as HTML. Not fixed; noted for the review.
4. **A clipboard write made while the window has no focus never settles.** Early in the check, Copy stayed busy for good, because `navigator.clipboard.writeText` waits while the WebView isn't focused. Once CDP focus emulation was on, both copies worked. A person pressing Copy focuses the window, so this only affects automation. Not fixed.
5. **Someone else used the window during the check.** Between the check's own steps, the focus log showed focus moving to a row, to the command palette and back. Later, `marshell-app` exited (00:23:48), in the same second as Vite's hot update of `TerminalView.tsx` for finding 1, and `tauri dev` ended its sessions. The cause of the exit wasn't found. The run was restarted on the same scratch home for the re-check of finding 1.
