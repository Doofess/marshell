## Findings

1. **A WSL tab opened as an agent tab keeps its agent row after the agent exits.** Resume runs `claude --resume …; exec bash -l`, so the tab outlives Claude. After `/exit`, `SessionEnd` arrived (`/v1/hook/events`), but the row stayed "Claude Opus 5.5, Idle". In a WSL tab, `server/hook.rs` skips the fold on `SessionEnd` and leaves the clearing to `clear_hook_agent`, which clears only an agent the hooks marked. An agent tab's agent comes from its launch, so nothing clears it. To be fixed in the slice's fix pass.
2. **The Codex WSL setup card repeats the trust sentence:** "Codex asks you to trust them in /hooks. Then trust them in Codex's /hooks inside Marshell-LC." To be fixed in the fix pass.
3. **The setup card's heading doesn't name the distro.** Only the diff path does, while the turn-off panel says "Turn Claude Code hooks off in Marshell-LC". To be fixed in the fix pass.
4. **An agent tab in a WSL profile shows "Status limited · set up" with the Windows setup link until a hook arrives.** The row checks the Windows hooks state. It stays that way when the agent never starts: the first Resume failed only because of root's `PATH` (test setup). Not fixed yet.
5. **Before the first hook, a WSL row names Windows interop children,** such as "Running wslhost", or "Running powershell" for Codex's clipboard helper. The foreground watcher sees only the Windows side. Known limit.
6. **A WSL tab's folder doesn't follow `cd`.** The row and the palette's file list keep the folder the tab started in. Known limit.
7. **The launcher starts an agent for a `\\wsl.localhost` folder with the Windows CLI.** Choosing Antigravity for `\\wsl.localhost\Marshell-LC\root\proj` started `agy.exe --mode auto` under the `pwsh` profile, signed out. Launching agents into a distro is not a slice 6j1 decision. Agents run in WSL when typed in a WSL tab, or through History's Resume. Known limit.
8. **A CLI update in a distro takes up to 10 minutes to show.** The version is cached per distro (`WSL_VERSION_TTL`), so after the switch to Codex 0.163.0, the row kept 0.166.0's "not recorded" note until a restart. Known limit.
9. **Removal previews were slow on a warm app.** The first was over 8 s. After a restart they took about 4.2 s. Not fixed.
10. **A WSL tab's Codex leaves the shared app-server daemon running in the distro after it quits** (0.166.0's `codex app-server`, started by the earlier runs). This is Codex's own behavior. The check ended it by terminating the scratch distro.
