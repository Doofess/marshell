## Findings

1. **`marshell open localhost:3000` got no hint.** On Windows the core refuses `<folder>\localhost:3000` before it looks for the file, since a colon in a file name names a stream, so the answer was "That path can't be opened in the side pane." and the CLI, which hinted only after "No file", said nothing about the address. The unit test used a fake that answered "No file". Fixed in `a4299e4d`: the CLI hints after either line for text that looks like a host; `open_run_hints_at_the_whole_address` failed first.
2. **Several tabs opened at once are not all heard.** The shared announcer speaks at most once per 1.5 s and keeps only the newest waiting message (`announce-policy.ts`). `marshell open README.md other.pdf` sends two requests, so two frames; README was heard, other.pdf waited, and "Session 1, PowerShell 7", which the session says when a command ends, replaced it. Not fixed: it is the policy every announcement shares, and the tab names still end ", new". PLAN §9 records it.
3. **The region box on a web page was named "…, page 1".** `describeRegion` always named a page, which a web page doesn't have. Fixed in `ec2b1a91`: `RegionLayer` takes `paged`, the browser tab passes false; `leaves the page out where there are no pages` and `names the box without a page number` failed first. An image in Preview says "page 1" the same way and is left as it was (it predates this slice).
4. **A first address that redirects to a refused one leaves the tab blank.** The tab's address becomes `about:blank` and the tooltip loses the address `marshell open` sent. The refusal line says why. Not fixed; noted for 6q-4's tab work.
5. **A shell session re-announces its name when a command ends.** "Session 1, PowerShell 7" was heard after every command, `marshell open` or not. It predates this slice; noted only because it can replace an open announcement (finding 2).
6. **Qwen's first prompt from the launcher is submitted.** The launcher passes it with Qwen's own `-i`, so Qwen starts working on it. That is how every agent with a prompt flag starts (`catalog.rs`), and `marshell new --prompt` still only fills the line. Not a change in this slice.
