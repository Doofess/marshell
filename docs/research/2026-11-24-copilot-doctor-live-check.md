## Findings

1. **After "Keep my file", the focus fell to the dialog instead of "Stop keeping".** The check a press starts hides the rows for a moment, so the focus went to the page itself, which the code did not count as lost. Fixed in `7bee147c`: `keepFocusLost` counts the page too. Its test ("the focus counts as lost on nothing, the body or the page itself, and not on another control") failed first. Checked again in the app in both directions.
2. **The final review's two findings were fixed before the check** (`0b28aa68`: turning the hooks off in a kept file no longer reads as "hooks are gone"; `dbe7742b`: a project skill and a personal skill of one name are both report-only). The first is in the table above.
3. **With only the hooks file deleted, the item reads "hooks are incomplete", not "are gone".** Marshell's status line is still in `settings.json`, so the install counts as partial, and the detail says "Some of Marshell's entries in …marshell.json are missing or changed" about a file that isn't there. The fix is the same and worked. "Are gone" shows when the status line is gone too (seen in Ubuntu). Not fixed.
4. **Turning off a skill that doesn't load doesn't quiet Copilot.** With `longdesc` in `disabledSkills`, `copilot skill list --json` left it out, but still printed "The following skills failed to load: …longdesc\SKILL.md: Skill description must be at most 1024 characters", and a new session still said "Failed to load 1 skill.". Marshell's item goes away; Copilot's warning stays until the description is shortened. Not fixed.
5. **The "runs your own Notification hook" row names `hooks\marshell.json` as its file** when the hook is in `hooks\mine.json`. Already on the slice's list of deferred minors. Not fixed.
6. **The fix preview's footer says "A backup is saved first, in ~/.marshell/snapshots/."** whatever the home is; the Agents consent step names the real folder (`C:\dev\lc-6n3-2\mh\snapshots`). Older than this slice. Not fixed.
7. **After "Undo last fix", the row that was ticked for that fix is still ticked.** Not looked into.
8. **Under a scratch `USERPROFILE`, onboarding refuses Claude Code, Antigravity and Qwen Code:** "Marshell will not edit …: The path is outside the home folder and the project folders." The guard reads the real profile. A limit of the check, not of this slice.
9. **In a distro the built-in GitHub server always counts.** With no `mcp-config.json` in Ubuntu the Doctor still said its servers weren't measured, because Marshell can't see whether Copilot runs offline there. As decided for the built-in server (decision "like any server"). Not fixed.
10. **"Remove from Ubuntu" leaves `settings.json` holding `{}` and an empty `hooks` folder** in the distro's `~/.copilot` (finding 9 of 6n2's check). Both were removed by hand at the end.
11. **A Copilot tab started in Ubuntu read "Idle · Status limited" until its first prompt,** while Copilot showed its folder-trust question. After the prompt it read "marshell-fake · Done". Not looked into.
