## Findings

1. **The same scripts asked twice on a machine with `core.autocrlf`.** The main checkout's `marshell.json` had LF endings, the new worktree's copy was checked out with CRLF, and the hash covered the raw bytes, so "Allow and create" was followed by "Allow and run setup" for identical scripts, and the second Allow replaced the first entry. Fixed in 41c44bc: the hash reads CRLF as LF (a newline inside a JSON string is always escaped, so this never changes a script). Test `line_endings_dont_change_the_hash`, RED then GREEN. Re-checked: an LF main copy and a CRLF worktree copy asked once.
2. **The row's name ended "Setup failed (exit 2).."** The note's own period was followed by the name's. Fixed in 506f53f; `labels.test.ts` "reads a setup note where the row draws it", RED then GREEN. Re-checked live.
3. **The row's "Open its output" button covered "set up" and "Review changes", and cut the status to "Statu…".** Three absolutely placed buttons don't fit a 280 px row. Fixed in ce0b3a0: the action is the row menu's "Open setup output" (before "Review changes"), and the note stays on the second line. Tests in `sessionMenu.test.ts`, `sessionMenuRun.test.ts` and `SessionRow.test.tsx`, RED then GREEN. Re-checked live by keyboard. On a selected or hovered task row whose hooks aren't set up, the "set up" and "Review changes" buttons still take the phrase's room (as before this slice), so the note is read there from the name and the tooltip.
4. **A script tab's footer said "Resume runs custom".** Script tabs started as the `custom` profile. Fixed in 1167e05: they start as the default profile with the script as argv (no shell integration injected), so Resume and Restart run that profile's shell. `scripts_api.rs` `run_starts_a_named_session_in_the_checkout_root` now asserts the profile, RED then GREEN. Re-checked: "Resume runs PowerShell 7 in …\epsilon".
5. **One WebSocket 404 in the console** (`/v1/pty/<tab>` during the first task's start). Seen once, not again after the reload; not investigated, and nothing in the UI went wrong.
